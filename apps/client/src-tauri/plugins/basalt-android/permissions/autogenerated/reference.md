## Default Permission

What the Basalt interface may ask of Android directly. Opening files and creating downloads are Rust's alone, so no page can reach a file descriptor.

#### This default permission set includes the following:

- `allow-pick-files`
- `allow-pick-folder`
- `allow-list-folder`
- `allow-open-with`
- `allow-open-download`
- `allow-share-download`
- `allow-take-shared`
- `allow-keep-alive`
- `allow-let-go`
- `allow-set-immersive`
- `allow-set-orientation`
- `allow-minimize`
- `allow-install-apk`
- `allow-can-install-apks`
- `allow-open-install-settings`
- `allow-haptic`
- `allow-player-levels`
- `allow-set-brightness`
- `allow-set-volume`
- `allow-notify-update`
- `allow-take-action`
- `allow-request-notifications`
- `allow-insets`
- `allow-register-listener`
- `allow-remove-listener`
- `allow-mpv-init`
- `allow-mpv-command`
- `allow-mpv-set-property`
- `allow-mpv-get-property`
- `allow-mpv-add-subtitle`
- `allow-mpv-destroy`
